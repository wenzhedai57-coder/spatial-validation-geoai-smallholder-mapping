# Author-resolved 525-record analysis

This folder contains the rerun based on the W.D. author-led VHR re-review and internal resolution. It uses the 525-record author-resolved working label set, but it does not provide a complete four-fold q25 spatial estimate.

- Included records: 525.
- Rubber records: 16, below the prespecified minimum class count of 30.
- Indicator q25 distance: approximately 158.5 km.
- Spatial folds: three estimable; one not estimable because buffering leaves no training samples.
- Target four-fold q25 estimate: not estimable under current support.

The term `author-resolved` denotes internal author resolution and must not be interpreted as independent validation.
