# Data availability

The repository contains the reference tables, feature matrices, configurations, scripts, run logs, predictions, result tables, support audits, figure files, and the exact current supplementary reproducibility directory. The manuscript cites a fixed commit URL generated after these files were synchronized.

The 525-record author-resolved working label set and the 622-record original-label sensitivity benchmark are separate estimands. Historical `verified` filenames and fields are documented in `data/REFERENCE_LABEL_SEMANTICS.md`. Licensed VHR imagery is not redistributed; decision and provenance logs are provided instead.
